# Viettel SMS Brandname Client (Python)

Thư viện Python giúp tích hợp dễ dàng hệ thống **Viettel SMS Brandname version 2**, hỗ trợ tự động xác thực, quản lý token, tự động làm mới khi hết hạn và hỗ trợ hệ thống quản lý Template tin nhắn động.

## Cài đặt

Cài đặt trực tiếp từ thư mục mã nguồn:
```bash
pip install .
```
